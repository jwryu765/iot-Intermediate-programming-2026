### 복사생성자

- 얕은 복사

    - 원본과 복사본이 같은 메모리 주소를 공유

    - 원본이 먼저 소멸되면 → 메모리 해제됨

    - 복사본은 이미 해제된 메모리를 가리키게 됨 (댕글링 포인터)

- 깊은 복사

    - 복사 시 새로운 메모리 할당

    - 원본이 소멸되어도

    - 복사본은 자기 메모리가 있으므로 안전하게 유지됨
